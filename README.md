# Autocxx

> [!NOTE]
Autocxx is no longer maintained by Google. If you rely on the project, you might want to consider supporting an actively maintained fork, such as https://github.com/Choochmeque/autocxx.

> [!NOTE]
As a new user, you might consider using [cxx](http://cxx.rs/) or [crubit](https://github.com/google/crubit) instead.

The original [README.md](README-orig.md) is available for reference purposes.
